# footer-links

Custom **footer** block. Purpose: footer link groups.

## Authoring (Universal Editor)

Container block `footer-links` with `footer-links-group` items.

Each row = group: title | rich text (link list, or sub-headings each followed by a list, or paragraphs). Desktop: columns (a group with sub-headings takes a full row); mobile: accordion.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
