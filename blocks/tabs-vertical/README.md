# tabs-vertical

Custom **tabs** block. Purpose: capability tabs.

## Authoring (Universal Editor)

Container block `tabs-vertical` with `tabs-vertical-item` items.

Each row = tab: tab label | rich text (heading, paragraph, link). Stacked labels on the left, the selected tab's white detail card on the right.

Styling expects the Broadridge page tokens (`body.broadridge`, styles/broadridge.css) and falls back to the design values.

## Supported variations

None.
