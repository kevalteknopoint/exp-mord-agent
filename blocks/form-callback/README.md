# form-callback

Custom **form** block. Purpose: callback-form.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: optional intro rich text; row 2: submit link (label = button text, href = POST endpoint); row 3: consent rich text; row 4: optional success message. NRI toggle, name, mobile (+91) and consent checkbox rendered by JS.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
