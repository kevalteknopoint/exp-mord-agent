# cards-shortcut

Custom **cards** block. Purpose: shortcut cards.

## Authoring (Universal Editor)

Container block `cards-shortcut` with `cards-shortcut-card` items.

Each row = card: icon | rich text (heading, subtitle, link). The link makes the whole card clickable; a red diagonal arrow sits top right.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
