# hero-split

Custom **hero** block. Purpose: split hero.

## Authoring (Universal Editor)

Container block `hero-split` with `hero-split-item` items.

Row 1 = main navy panel (heading, intro paragraph, CTA link rendered as a white button; optional background image). Rows 2+ = promo cards stacked on the right (tag paragraph before the heading, heading, link rendered as an arrow; optional background image).

Styling expects the Broadridge page tokens (`body.broadridge`, styles/broadridge.css) and falls back to the design values.

## Supported variations

None.
