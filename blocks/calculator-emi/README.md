# calculator-emi

Custom **calculator** block. Purpose: EMI calculator.

## Authoring (Universal Editor)

Key-value block.

Key-value block: price range + default (₹), down payment range (% of price), tenure options + recommended, interest range + default, CTA label + link, disclaimer note. Computes the monthly EMI live.

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
