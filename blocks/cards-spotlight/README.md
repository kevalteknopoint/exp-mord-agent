# cards-spotlight

Custom **cards** block. Purpose: insight cards.

## Authoring (Universal Editor)

Container block `cards-spotlight` with `cards-spotlight-card` items.

Each row = card: photo | rich text (tag paragraph such as "Content type", heading, link). Photo on top, navy body; the link renders as an arrow and makes the card clickable.

Styling expects the Broadridge page tokens (`body.broadridge`, styles/broadridge.css) and falls back to the design values.

## Supported variations

None.
