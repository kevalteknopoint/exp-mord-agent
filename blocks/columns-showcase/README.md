# columns-showcase

Custom **columns** block. Purpose: feature showcase.

## Authoring (Universal Editor)

Simple block.

Block fields: large visual | rich text (heading, paragraph, CTA). Desktop: visual left, right-aligned text bottom right; mobile: text, visual, CTA.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
