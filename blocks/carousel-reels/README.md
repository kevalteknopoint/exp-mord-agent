# carousel-reels

Custom **carousel** block. Purpose: customer video stories.

## Authoring (Universal Editor)

Container block `carousel-reels` with `carousel-reels-card` items.

Each row = story: poster | rich text (quote paragraph, bold name, meta paragraph, tag paragraph) | video link | duration.

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
