# cards-impact

Custom **cards** block. Purpose: content cards.

## Authoring (Universal Editor)

Container block `cards-impact` with `cards-impact-card` items.

Each row = card: illustration | rich text (tag paragraph, heading, description, link - shown as a round play button for video/podcast tags, arrow otherwise) | theme (light, red = raised feature card). Mobile: swipe row with dots.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
