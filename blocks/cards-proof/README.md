# cards-proof

Custom **cards** block. Purpose: proof points.

## Authoring (Universal Editor)

Container block `cards-proof` with `cards-proof-item` items.

Each row = proof point: rich text (value heading, label paragraph, description, optional link shown as a corner arrow).

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
