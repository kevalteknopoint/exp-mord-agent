# tabs-plans

Custom **tabs** block. Purpose: plan tabs.

## Authoring (Universal Editor)

Container block `tabs-plans` with `tabs-plans-card` items.

Each row = plan card: tab label (cards sharing a label form one tab) | illustration | rich text (optional badge paragraph before the heading, heading with bold words highlighted in red, description, link).

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
