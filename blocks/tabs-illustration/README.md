# tabs-illustration

Custom **tabs** block. Purpose: benefit-illustration.

Single block table. Content: each row = tab: cell1 tab label; cell2 persona (avatar image, heading, description, attribute list); cell3 timeline (step images, list of steps with age label/title/caption, CTA link).
