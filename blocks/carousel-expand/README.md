# carousel-expand

Custom **carousel** block. Purpose: video testimonials.

## Authoring (Universal Editor)

Container block `carousel-expand` with `carousel-expand-item` items.

Each row = video story: poster image | rich text (caption paragraph, link to the video shown as a red play button). The active story is wide, the others are narrow peeks that expand on click.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
