# filter-dropdowns

Custom **filter** block. Purpose: filter bar.

## Authoring (Universal Editor)

Container block `filter-dropdowns` with `filter-dropdowns-item` items.

Each row = filter: label | rich text list of option links. Renders a bar of toggles, each opening its option panel.

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
