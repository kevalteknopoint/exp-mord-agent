# carousel-showcase

Custom **carousel** block. Purpose: car hero carousel.

## Authoring (Universal Editor)

Container block `carousel-showcase` with `carousel-showcase-slide` items.

Each row = slide: car image | rich text (heading, model paragraph, price paragraphs with the amount in bold, an italic-only paragraph = availability badge, CTA links - an italic link is the outline button). Dots + autoplay.

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
