# cards-metric

Custom **cards** block. Purpose: stats tiles.

## Authoring (Universal Editor)

Container block `cards-metric` with `cards-metric-card` items.

Each row = tile: image (portrait for a quote, line art for stats) | rich text (stat value heading + label, or quote + bold name + role) | style (quote, red-tall, red, light). Quote and tall tiles span two rows.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
