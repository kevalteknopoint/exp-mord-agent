# hero-statement

Custom **hero** block. Purpose: statement hero.

## Authoring (Universal Editor)

Simple block.

Block fields: desktop artwork | optional mobile artwork | rich text (h1 statement with bold words, tagline paragraph rendered with a red circle, optional scroll-down link). Dark full-bleed hero; the header floats over it.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
