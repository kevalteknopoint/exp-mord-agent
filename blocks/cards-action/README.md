# cards-action

Custom **cards** block. Purpose: quick actions.

## Authoring (Universal Editor)

Container block `cards-action` with `cards-action-card` items.

Each row = action: icon | rich text (heading, description, optional italic-only paragraph = chip, link shown as a square arrow button).

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
