# search-prompt

Custom **search** block. Purpose: prompt search bar.

## Authoring (Universal Editor)

Simple block.

Block fields: prefix ("I want to") | suggestions (comma separated, rotated in bold while the field is empty) | search page URL (query sent as ?q=). Shows a voice button where the browser supports speech recognition.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
