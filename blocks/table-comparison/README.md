# table-comparison

Custom **table** block. Purpose: plan-comparison.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: first row = header (label title + plan names); each next row = attribute label cell + one rich-text value cell per plan; bold-only paragraphs (Minimum/Maximum) split a value into sub-rows; last row with empty label + links = CTA buttons.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
