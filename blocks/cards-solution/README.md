# cards-solution

Custom **cards** block. Purpose: solution cards.

## Authoring (Universal Editor)

Container block `cards-solution` with `cards-solution-card` items.

Each row = card: illustration image | rich text (heading, short description, link). The link renders as an arrow at the bottom and makes the whole card clickable.

Styling expects the Broadridge page tokens (`body.broadridge`, styles/broadridge.css) and falls back to the design values.

## Supported variations

None.
