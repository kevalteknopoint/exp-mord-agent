# carousel-promo

Custom **carousel** block. Purpose: promo banner carousel.

## Authoring (Universal Editor)

Container block `carousel-promo` with `carousel-promo-slide` items.

Each row = slide: photo | rich text (tag paragraph, heading, CTA link rendered as a white pill, fine-print paragraph) | stats list (one item per stat, value in bold). Dots + gentle autoplay.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
