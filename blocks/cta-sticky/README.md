# cta-sticky

Custom **cta** block. Purpose: sticky mobile CTA bar.

## Authoring (Universal Editor)

Simple block.

Block field: rich text (info paragraph, CTA links). Fixed bar at the bottom of the screen on mobile; hidden on desktop.

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
