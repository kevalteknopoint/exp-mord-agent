# carousel-reviews

Custom **carousel** block. Purpose: testimonial.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: each row = review card: cell1 round avatar image, cell2 rich text (reviewer name heading, plan name, date, rating paragraph e.g. 4/5, Watch Video link, quote text).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
