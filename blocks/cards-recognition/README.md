# cards-recognition

Custom **cards** block. Purpose: recognition cards.

## Authoring (Universal Editor)

Container block `cards-recognition` with `cards-recognition-card` items.

Each row = card: optional image | rich text (heading, link). A card with an image becomes the large feature card (image fills the card); text-only cards stack beside it.

Styling expects the Broadridge page tokens (`body.broadridge`, styles/broadridge.css) and falls back to the design values.

## Supported variations

None.
