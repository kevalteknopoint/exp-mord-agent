# tabs-faq

Custom **tabs** block. Purpose: faq-tabs.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: optional first single-cell row = collapsible title; each next row = tab: cell1 tab label, cell2 rich text (question headings + answer paragraphs, numbered automatically).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
