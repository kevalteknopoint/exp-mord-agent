# cards-car

Custom **cards** block. Purpose: car cards.

## Authoring (Universal Editor)

Container block `cards-car` with `cards-car-card` items.

Each row = car: image | rich text (linked model name heading, social-proof paragraph, fuel list with ' · ' separators - EV is highlighted, price paragraphs with the amount in bold, tenure paragraph, CTA links - italic link = outline) | offer line.

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
