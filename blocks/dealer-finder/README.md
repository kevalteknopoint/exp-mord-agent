# dealer-finder

Custom **form** block. Purpose: dealer search.

## Authoring (Universal Editor)

Key-value block.

Key-value block: field label | default pincode | result text | map image | dealer locator page (search sent as ?pincode=).

Styling expects the Tata Cars page tokens (`body.tatacars`, styles/tatacars.css) and falls back to the design values.

## Supported variations

None.
