# tabs-feature

Custom **tabs** block. Purpose: industry tabs.

## Authoring (Universal Editor)

Container block `tabs-feature` with `tabs-feature-item` items.

Each row = tab: tab label | image | rich text (heading, paragraph, link). Horizontal underlined tab list; the panel shows the image beside the text.

Styling expects the Broadridge page tokens (`body.broadridge`, styles/broadridge.css) and falls back to the design values.

## Supported variations

None.
