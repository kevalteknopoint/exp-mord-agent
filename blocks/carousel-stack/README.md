# carousel-stack

Custom **carousel** block. Purpose: stacked offer cards.

## Authoring (Universal Editor)

Container block `carousel-stack` with `carousel-stack-card` items.

Each row = offer card: rich text (tag paragraph, lead-in paragraph, heading with the bold amount, follow-up paragraph). Cards stack with the next ones peeking out; numbered pager + autoplay.

Styling expects the Kotak page tokens (`body.kotak`, styles/kotak.css) and falls back to the design values.

## Supported variations

None.
